## Bugs found & fixes

| ID | Symptom | Root cause | Fix | Tests |
| --- | --- | --- | --- | --- |
| B1 | Mass client disconnect @ 100 bots, `fineage_outbound_dropped_total` hundreds | Per-connection outbound channel (default 32) saturated under full-world NPC fanout; only MoveState coalesced on wire | Coalesce **StatusUpdate** + **AbnormalStatusUpdate** like MoveState; local stress uses `FINEAGE_ZONE_OUTBOUND_QUEUE=512` | Existing `NetMoveStateCoalesceTests` |
| B2 | Load test crash at end | Oracle `First()` on roster after partial disconnects | `FirstOrDefault` + skip | `Fineage.LoadTest.Tests` |
| B3 | False consistency FAIL (stale position / HP) | Compared observer A's view of B to B's view of A | Ground truth = peer self-tracked state; soft warnings only | Oracle logic |
| B4 | Flaky `ZoneSimulationTickBudgetTests` | p99 on wall time under GC | GC warmup + **median** + max guard | Same test (stable) |
| B5 | Ledger flush failures invisible in scrape | Metric not exported | `fineage_ledger_flush_failures_total` in `/metrics` | Parser + existing ledger barrier tests |
